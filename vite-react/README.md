# Vite + React

The Vite + React starter homemade.dev puts in a new template project, made with `create vite` (react-ts) and regenerated every week by [usehomemade/templates](https://github.com/usehomemade/templates). `pnpm dev` runs it with hot reload; `.homemade/config.json` has the install command and the dev server homemade starts.
