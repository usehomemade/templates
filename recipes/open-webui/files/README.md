# Open WebUI + Ollama

[Open WebUI](https://github.com/open-webui/open-webui) (Open WebUI License: BSD-3-Clause with a branding clause) talking to [Ollama](https://github.com/ollama/ollama) (MIT) with a small CPU model, `qwen2.5:0.5b`, already pulled. Both run from their official Docker images; this folder only holds the homemade config. Login is off (`WEBUI_AUTH=False`) because the VM is yours.

There is no dev mode here: these are released apps, not source you edit.
