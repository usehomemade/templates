# Django

The Django starter homemade.dev puts in a new template project, made with `uv init` and `django-admin startproject` and regenerated every week by [usehomemade/templates](https://github.com/usehomemade/templates). `uv run manage.py runserver` runs it and reloads on save; `.homemade/config.json` has the install command and the dev server homemade starts.
